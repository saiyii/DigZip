# DigZip 0.2.0

DigZip now has a window. This release adds `digzip-gui`, a graphical interface built on the
same engine as the command-line tool, and ready-to-run downloads for every system.

## Downloads

| File | For |
|---|---|
| `digzip-gui-0.2.0-windows-x64.zip` | **Windows 10 and 11**: the graphical interface (`digzip-gui.exe`) and the command-line tool |
| `digzip-gui-0.2.0-macos-universal.zip` | **macOS 12 or later**, Apple Silicon and Intel: `DigZip.app` |
| `digzip-0.2.0-windows-x64.zip` | Command-line tool only, a single `digzip.exe` |
| `digzip-0.2.0-linux-x64.tar.gz` | Command-line tool for Linux (x64, glibc 2.35 or later) |
| `digzip-0.2.0-macos-universal.zip` | Command-line tool for macOS |
| `SHA256SUMS.txt` | Checksums of the files above |

Unpack and run; nothing to install. The programs are not signed yet: Windows may show
"Windows protected your PC" (choose *More info*, then *Run anyway*), and macOS asks to confirm
the first opening (right-click `DigZip.app`, then *Open*).

## The graphical interface

- Open an archive with *Open*, by dropping it on the window, or by passing it to `digzip-gui`.
- The content is listed with sizes, dates, methods and encryption; sort it by any column and
  filter it by name.
- Choose the destination folder (by default a folder named after the archive, next to it) and
  what to do with files that already exist: keep them, replace them, or keep both.
- *Extract* and *Test* run in the background with a progress bar; *Cancel* (or Esc) stops
  cleanly and never leaves a half-written file.
- A password is asked when the archive needs one, and asked again only for the files a wrong
  password could not decrypt.
- Any problem (damaged data, refused path, existing file) is listed under the content.

Every format, method and safety rule of the engine applies: ZIP, 7z, RAR 5, TAR and single
`.gz` / `.bz2` / `.xz` / `.zst` files, with their encryption.

## Licenses

DigZip itself stays under MIT or Apache-2.0. The graphical interface uses Qt 6.10.3 under the
LGPLv3; Qt is shipped as separate, unmodified libraries, and the downloads include the license
texts and where to get the Qt source code.

## Known limitations

- The interface is in English for now; French and English translations come next.
- No graphical package for Linux yet (the command-line tool is available): an AppImage comes
  with the installers.
- No installer, file association or "Extract here" context menu yet: they are planned for 1.0.
- Everything listed in the [0.1.0 notes](0.1.0.md) still applies (no RAR 4, no multi-part
  archives, single-threaded extraction).

## Verification

- Qt Test suite for the interface (content model, background jobs, cancellation, password
  retries, drag and drop, the main window end to end), run without a screen on Linux, macOS
  and Windows in CI, next to the existing engine and CLI tests.
- The Windows package checked on a machine without Qt: it starts, lists and extracts.
- AddressSanitizer + UndefinedBehaviorSanitizer and fuzzing jobs unchanged and passing.
