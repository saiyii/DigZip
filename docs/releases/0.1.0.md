# DigZip 0.1.0

First release of DigZip, a fast, multi-format and safe archive extractor written in C++17,
usable as a library and from the command line.

## Highlights

- **Reads** ZIP, 7z, TAR (plain, `.tar.gz`, `.tar.bz2`, `.tar.xz`, `.tar.zst`) and single
  `.gz`, `.bz2`, `.xz`, `.zst` files, with every common method: deflate, Deflate64, bzip2,
  LZMA, LZMA2, PPMd, xz, zstd, and the BCJ, BCJ2 and Delta filters.
- **Decrypts** ZipCrypto, WinZip AES and 7z AES archives, including 7z archives with
  encrypted file names. Several passwords can be tried in turn.
- **Refuses** whatever would escape the destination (absolute paths, `..`, drive letters,
  escaping links), stops decompression bombs, and never leaves a half-written file.
- **Scripts well**: `--json` output and exit codes that tell what went wrong.

## Getting started

```sh
digzip list archive.zip
digzip extract archive.7z -o out/
digzip test backup.tar.zst
digzip extract secret.zip --password-file passwords.txt --overwrite rename
```

Run `digzip --help` for every option. The library API is in `engine/include/digzip/`
(see the README for an example).

## Compatibility

- Windows 10+, macOS and Linux; MSVC 2022, GCC 9+ or Clang 10+.
- The C++ API may change during 0.x. The stable C API comes with 1.0.

## Known limitations

- RAR archives are not supported yet (planned as an optional module).
- Multi-part archives (`.001`, `.z01`, `.part1.rar`) are not supported yet (planned for 1.0).
- Not supported: tar sparse files and multi-volume tar, PKWARE strong encryption,
  7z branch filters (BCJ, ARM64...) applied on top of a method other than LZMA / LZMA2.
- On Windows, creating symbolic links needs Developer Mode or administrator rights; without
  them, links to files are extracted as copies and the others are skipped, with a warning.
- Extraction is single-threaded; parallel ZIP extraction and the performance work come with 1.0.

## Verification

- Unit, integration and CLI tests, with valid, hostile and corrupt archives.
- Extraction compared byte for byte with 7-Zip and Python on real-world archives (software
  source trees, PowerShell, 7-Zip itself), in every supported method and encryption.
- Test suite under AddressSanitizer and UndefinedBehaviorSanitizer; fuzzing of the archive
  readers, the decoders written for DigZip and the path rules.
